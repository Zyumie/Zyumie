### 🛠️ Mes Projets & Plugins

* **[PiglinSMP-V2](https://github.com/Zyumie/PiglinSMP-V2)** — Système de loot personnalisé basé sur le troc des Piglins avec 7 armes uniques aux mécaniques spéciales.
* **[GuardianOfNether](https://github.com/Zyumie/GuardianOfNether)** — Boss sur mesure protégeant le Nether.
* **[FireBallWand](https://github.com/Zyumie/FireBallWand)** — Bâton magique pour lancer des boules de feu *(Minecraft 1.20+)*.
* **[HardcoreZ](https://github.com/Zyumie/HardcoreZ)** — Plugin pour le mode Hardcore *(Minecraft 1.21)*.
* **[NoMaceEnchant](https://github.com/Zyumie/NoMaceEnchant)** — Désactive les enchantements de la masse.
* **[DamageCible](https://github.com/Zyumie/DamageCible)** — Plugin de gestion des dégâts pour *King of Kill*.
